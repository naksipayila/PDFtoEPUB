PDF to EPUB taşınabilir Windows paketi

Kullanim:
1. Bu klasoru baska bir Windows bilgisayara kopyalayin.
2. PDFtoEPUB.exe dosyasina cift tiklayin.
3. Python, pip, PySide6, PyMuPDF veya baska bir Python kurulumu gerekmez.

Notlar:
- Uygulama pencere modunda acilir; terminal penceresi gostermez.
- Donusum ciktilarini bu klasorun disinda secmeniz onerilir.
- OCR, paket olusturulurken Tesseract bulunuyorsa pakete dahil edilir.
- Tesseract dahil degilse metin katmani olan PDF'ler yine normal sekilde donusturulur.

Bu dosya, build_portable.cmd ile olusturulan pakete otomatik olarak kopyalanir.
